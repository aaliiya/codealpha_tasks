# 📌 Project 1: Hangman Game

## 🎮 Description

A modern responsive Hangman Game where the player guesses letters to reveal a hidden word.

---

## ✨ Features

- Responsive modern UI
- Random word generation
- 5 predefined words
- Guess letters one by one
- Maximum 6 incorrect attempts
- Win/Loss tracking
- Restart game functionality
- Keyboard support
- Animated hangman drawing
- Error handling for duplicate guesses

# 📌 Project 2: Rule-Based Chatbot

## 🤖 Description

A simple rule-based chatbot with predefined responses and a modern chat interface.

---

## ✨ Features

- Rule-based chatbot
- 10+ predefined responses
- Attractive responsive UI
- Typing indicator animation
- Auto-scroll chat window
- Keyboard Enter support
- Clear chat button
- Timestamps for messages
- Glassmorphism design
- User and bot message alignment
- Responsive mobile-friendly layout
