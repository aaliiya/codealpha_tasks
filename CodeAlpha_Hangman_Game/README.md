# 🎯 Hangman Game

A modern responsive Hangman Game built using HTML, CSS, JavaScript, and Python Flask.

---

# Features

- Responsive modern UI
- Random word generation
- 5 predefined words
- Guess letters one by one
- Maximum 6 incorrect attempts
- Win/Loss tracking
- Restart game functionality
- Keyboard support
- Animated hangman drawing
- Error handling for duplicate guesses

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
