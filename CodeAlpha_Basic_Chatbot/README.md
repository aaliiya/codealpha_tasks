# 🤖 Rule-Based Chatbot Website

A modern responsive chatbot website built using HTML, CSS, JavaScript, and Python Flask.

---

# Features

- Rule-based chatbot
- 10+ predefined responses
- Attractive responsive UI
- Typing indicator animation
- Auto-scroll chat window
- Keyboard Enter support
- Clear chat button
- Timestamps for messages
- Glassmorphism design
- User and bot message alignment

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
